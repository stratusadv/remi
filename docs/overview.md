# remi

## Overview

remi is a desktop app that turns a recording of a meeting into a formatted document, on Windows, macOS, and Linux. It transcribes the recording, then writes notes from a template you pick.

| Page | Description |
|------|-------------|
| Home | The page lists each recording. |
| Ask | The page answers a question about your recordings and names the ones it used. |
| Templates | The page holds the layouts a document can follow. |
| People | The page holds each person once, with a role and a description for the AI. |
| Buy hours | The page adds transcription hours to your account. |
| Settings | The page holds the theme, the recordings folder, your account, the API address, and the keys. |
