# scribe

## Overview

scribe is a desktop app that turns a recording of a meeting into a formatted document, on Windows and Linux. It transcribes the recording, then writes notes from a template you pick.

| Page | Description |
|------|-------------|
| Home | The page lists each recording. |
| Templates | The page holds the layouts a document can follow. |
| People | The page holds each person once, with a role and a description for the AI. |
| Settings | The page holds the theme, the recordings folder, the API address, and the keys. |
